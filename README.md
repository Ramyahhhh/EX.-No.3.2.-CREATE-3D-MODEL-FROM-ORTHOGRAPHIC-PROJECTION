# EX No.3.2. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION
## DATE:02-11-26
## REG NO : 26017329
## NAME: M RAMYA


## AIM:
To construct a 3D solid model of an Arched Mounting Bracket from the given 2D orthographic projections (Front, Top, and Side views) and generate its ISO drawing sheet using Autodesk Fusion 360.

## REQUIREMENTS:
• Software. Autodesk Fusion 360 (3D CAD/CAM modeling suite) with an active user account.

• Operating System. Microsoft Windows 10 (64-bit) operating system.

• Memory & Graphics. 16 GB RAM paired with integrated or dedicated graphics supporting 1 GB or more VRAM.

• Internet Connectivity. A stable broadband connection with at least 2.5 Mbps download and 500 Kbps upload speeds for cloud synchronization.

• Peripherals. A standard keyboard, a three-button scroll mouse, and a display monitor.


## PROCEDURE:
1. Initialize New File: Launch Autodesk Fusion 360, open a New Design file, and select the Create Sketch icon.
2. Select Sketching Plane: Choose the required reference plane (XY, YZ, or XZ) for sketching.
3. Create 2D Sketch: Open the Create menu and use sketching features (Line, Circle, Arc, Rectangle, Polygon, and Sketch Dimension) to draw the given profile.3.	Use sketching features (line, circle, arc, rectangle, polygon, etc.,) to draw the given sketch.

![image](https://user-images.githubusercontent.com/113594316/198823371-bacc7928-28aa-45dd-a652-8833f95e3ea9.png)

4.	Modify Sketch: Open the Modify menu and use editing features (Fillet, Chamfer, Trim, Extend, Offset, and Move/Copy) to refine the sketch.
   ![image](https://user-images.githubusercontent.com/113594316/198823384-c72c4c0f-9650-48db-b7da-697a0f22886b.png)

5.	Inspect Dimensions: Select Measure from the Inspect menu to verify the dimensions of the sketch.

![image](https://user-images.githubusercontent.com/113594316/198823390-0832a221-257e-439f-99b4-1a8beca74b56.png)

6.	Finalize Sketch: Click the Finish Sketch icon on the toolbar to finalize the 2D profile.

![image](https://user-images.githubusercontent.com/113594316/198823401-1b79c82e-7665-4874-8135-52cbce3bb50d.png)

7.Extrude 3D Model: Open the Solid > Create menu and select Extrude to convert the 2D sketch into a 3D solid model.

![image](https://user-images.githubusercontent.com/113594316/198823408-d3d678f1-2247-41a2-abdd-b9a8918daef8.png)


8.Generate ISO Drawing Sheet: After completing the 3D model, switch from Design to Drawing > From Design to convert the model into a 2D drawing sheet as per ISO standards.

![image](https://user-images.githubusercontent.com/113594316/198823415-9d0a9454-b197-44bf-b90f-179c75602500.png)
